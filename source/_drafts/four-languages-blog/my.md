Lebih kurang 2~3 minggu sebelum ini, saya telah merombakkan laman web ini. Sekarang, semua konten dalam laman web ini boleh dipaparkan dalam **bahasa Inggeris, bahasa Melayu, bahasa Cina Tradisional, dan bahasa Cina ringkas**.

Rombakan kali ini memang sesuatu operasi yang sangat besar, sekajap sahaja dah habiskan semua peruntukan token saya untuk bulan ini. Tema Hexo yang saya guna sekarang tidak menyokong post pelbagai bahasa, boleh katanya saya tambahkan fungsi ini secara paksa. Kod sumber laman web ini kita tak perlu pergi Github tengok pun boleh tahu betapa dahsyat strukturnya, hehehe~

Walaupun membina laman web pelbagai bahasa sangat menyusahkan diri, tapi aku fikir, aku orang Malaysia, kalau guna satu bahasa sahaja, semestinya tak boleh meliputi semua golongan yang mungkin baca blog saya. Saya tak harapkan blog saya ada pembaca, tetapi mungkin saya kehilangan peluang untuk orang lain mengenal saya?

Dari segi keliputan, sebenarnya bahasa Cina dan bahasa Inggeris dah cukup. Tetapi... sudah tentulah laman web ini akan dikena rombakan besar, kenapa saya tak tambah banyak sikit bahasa?

**Cina tradisional**: Cina, macam mana pun bahasa ibunda saya, itulah bahasa terbaik untuk mengungkapan idea saya. Biasanya saya menulis dalam bahasa Cina dulu, baru terjemahkan ke bahasa lain. Mempertimbangkan saya sentiasa menyertai BlogBlogParty, kebanyakkan pembaca blog ini orang Taiwan, yang mana lebih sesuai membaca Cina tradisional.

**Cina ringkas**: Tetapi saya orang Cina Malaysia, kebanyakkan kawan offline saya guna Cina ringkas, boleh baca Cina tradisional tak bermaksud mereka suka. Penukaran Cina tradisional ke Cina ringkas sangat senang, guna penterjemah sedia ada sahaja.

**English**: Whether I end up studying in Malaysia or abroad in the future, English will be the main language during my university years, and there's a good chance I'll be immersed in English-speaking circles for a long time. So I figured it's better to plan ahead.

**Malay**: If I want to discuss very local topics (politics?) and current events, I think expressing myself in Malay would flow more naturally than in Chinese. Again, I want to reach as many people as possible, at least within Malaysia. And of course, most importantly, I just enjoy doing it, so I'm willing to put in the effort.

### The Cost

But the cost of doing this is pretty significant. Every time I publish a post, I now need to rewrite it in English in Malay as well, and 2-3 hours has become the baseline production time just for one article. But as I've mentioned before, writing articles has always been extremely time-consuming and difficult for me, so I've already gotten used to the feeling that every article is a big project. As for older posts, I've already translated them into Simplified Chinese; O'll fill in the English and Malay versions whenever I get the chance later.

### Afterword

After finishing this overhaul of the site, I find myself feeling a bit regretful again: the site has gotten so bloated now. Either way, I can live with it, and honestly kind of like it, because it really suits my personality (much like my perpetually messy desk). But whether readers can live with it is a whole other matter. I believe all this fuss was worth it.
