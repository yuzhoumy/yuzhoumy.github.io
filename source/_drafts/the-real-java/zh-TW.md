# Wes Mangan?

説起 Java，大部分人都會想到程式語言，或者是Minecraft。但在世界的另一端，在硅谷的背面，**爪哇語（Basa Jawa/Javanese）** 是印尼一門超過8000萬人使用的語言哦！

爪哇語主要由爪哇人使用。雖然我居住在馬來西亞，但身邊不少馬來朋友都是爪哇裔後代，便多多少少接觸到爪哇文化了。
Wes mangan，在爪哇語中是呷飽沒的意思，恭喜你學會了你的第一句爪哇話啦~

### 滅絕危機

雖然爪哇語擁有8000萬使用者，但它**不是任何國家的官方語言**！這是爲什麽呢？
在1945年印尼獨立運動之時，開國元帥蘇加諾擔下了要統一全國的重任。統一的第一步，就是要統一語言。

![印尼的地圖](/images/post/indonesia-map.png)

但是印尼，可是擁有17000個島嶼，700種語言，7400萬人口的超複雜國家。如果選用接近一半人口使用的語言——爪哇語，那麽非爪哇族的人肯定會超不爽，憑什麽少數要服從多數？爲了防止種族衝突，蘇加諾做出了驚人的決定——使用當時僅有超少人用的語言——廖内馬來語設爲國語。由於對所有人來説都是外語，反而達成了公平。PS：新加坡使用英語作爲主要語言亦是同理。

從此，爪哇語就失去官方地位了……

### 真正的 JavaScript

除了可以用拉丁字書寫之外，爪哇語也有自己獨特又優美的文字！它叫做Aksara Jawa或Hanacaraka

![爪哇文字](/images/post/javanese-font.jpg)

世界上絕大多數文字的字母表，比如拉丁字的A, B, C, D...... 都沒有任何連貫的意義。
有趣的是，爪哇語的20個核心字母竟然可以組成一首**五言絕句**！

![hanacaraka](/images/post/hanacaraka.jpg)

《Hanacaraka》是一首悲壯的史詩，普遍上認爲與[阿吉 · 薩卡的傳奇有關](https://id.wikipedia.org/wiki/Aksara_Jawa#Pengurutan)。

> ꦲꦤꦕꦫꦏ
Hana Caraka
有兩個使者
ꦢꦠꦱꦮꦭ
Data Sawala
他們之間意見不合
ꦥꦝꦗꦪꦚ
Padha Jayanya
他們的力量旗鼓相當，不相上下
ꦩꦒꦧꦛꦔ
Maga Bathanga
最終雙雙戰死，留下兩具尸體

# Java 的音樂

甘美蘭（Gamelan，意為合奏）是爪哇人的傳統樂器，也是印尼歷史最悠久的樂器。甘美蘭的音調和西方樂器完全不同，并沒有統一的標準音調，因此**世界上沒有任何兩個音準相同的甘美蘭**。
