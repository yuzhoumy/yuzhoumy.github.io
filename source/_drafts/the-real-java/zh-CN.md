# Wes Mangan?

说起 Java，大部分人都会想到程序语言，或者是 Minecraft。但在世界的另一端，在硅谷的背面，**爪哇语（Basa Jawa/Javanese）** 是印尼一门超过 8000 万人使用的语言哦！

爪哇语主要由爪哇人使用。虽然我居住在马来西亚，但身边不少马来朋友都是爪哇裔后代，便多多少少接触到爪哇文化了。
Wes mangan，在爪哇语中是呷饱没的意思，恭喜你学会了你的第一句爪哇话啦~

### 灭绝危机

虽然爪哇语拥有 8000 万使用者，但它**不是任何国家的官方语言**！这是为什么呢？
在 1945 年印尼独立运动之时，开国总统苏加诺担下了要统一全国的重任。统一的第一步，就是要统一语言。

但是印尼，可是拥有 17000 个岛屿，700 种语言，1945 年就有 7400 万人口的超复杂国家。如果选用接近一半人口使用的语言——爪哇语，那么非爪哇族的人肯定会超不爽，凭什么少数要服从多数？为了防止种族冲突，苏加诺做出了惊人的决定——使用当时仅有超少人用的语言——廖内马来语设为国语。由于对所有人来说都是外语，反而达成了公平。从此，爪哇语就失去官方地位了……

冷知识 1：犹如 Java 中公私分明的函数一样，爪哇语也有一套**阶级系统**。爪哇语主要分为三个主要阶层：

* Ngoko（粗语）用于同龄人、同辈对晚辈
* Madya（中性语）用于陌生人
* Krama（高雅语）用于晚辈对长辈、下级对上级
这三种阶层的爪哇语，可是连基本词汇都不一样，所以我认为会爪哇语的人都超强，相当于一次学了三门语言。例如“吃”这个字，对朋友说是“mangan”，对长辈必须用“dahar”；“你”对朋友使用是“kowe”，对长辈使用是“panjenengan”。想用爪哇语聊天，你必须时刻掂量对方的身份，用错一个词汇都是极大的冒犯。这种见人说人话，见鬼说鬼话的体系，实在是太繁杂了，也是爪哇语没有成为印尼国语的原因之一。

冷知识 2：新加坡将英语设为核心行政与工作语言，是为了平衡三大民族之间的隔阂，亦是同理。

### 真正的 JavaScript

除了可以用拉丁字书写之外，爪哇语也有自己独特又优美的文字！它叫做 Aksara Jawa 或 Hanacaraka

世界上绝大多数文字的字母表，比如拉丁字的 A, B, C, D...... 没有任何连贯的意义。
有趣的是，爪哇语的 20 个核心字母竟然可以组成一首**五言绝句**！

《Hanacaraka》是一首悲壮的史诗，普遍上认为与[阿吉 · 萨卡的传奇有关](https://id.wikipedia.org/wiki/Aksara_Jawa#Pengurutan)。

> ꦲꦤꦕꦫꦏ
Hana Caraka
有两个使者
ꦢꦠꦱꦮꦭ
Data Sawala
他们之间意见不合
ꦥꦝꦗꦪꦚ
Padha Jayanya
他们的力量旗鼓相当，不相上下
ꦩꦒꦧꦛꦔ
Maga Bathanga
最终双双战死，留下两具尸体

# Java 的音乐

甘美兰（Gamelan，意为合奏）是爪哇人的传统乐器，也是印尼历史最悠久的乐器。甘美兰的音调和西方乐器完全不同，并没有统一的标准音调，因此**世界上没有任何两个音准相同的甘美兰**。

冷知识：德布西在 1889 年的巴黎博览会时，爪哇甘美兰给了他巨大的启发，在他的作品 [Estampes](https://youtu.be/R-YcnPXY2yE) 中的 Pagodes 乐章尤为明显。

### 那么 Java（程序语言）为什么会叫 Java 呢？

起初，创始人原本想要把它命名为“Oak”，因为创始人门口正对着一颗橡树。然而，在准备商业化推广时，发现 Oak 这个名字早就被注册了，被迫改名。此时，又因为创作团队人们对一种来自爪哇岛上的咖啡情有独钟，便决定将之命名为 Java。
