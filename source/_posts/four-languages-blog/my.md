Lebih kurang 2~3 minggu sebelum ini, saya telah merombakkan laman web ini. Sekarang, semua konten dalam laman web ini boleh dipaparkan dalam **bahasa Inggeris, bahasa Melayu, bahasa Cina Tradisional, dan bahasa Cina ringkas**.

Rombakan kali ini memang sesuatu operasi yang sangat besar, sekajap sahaja dah habiskan semua peruntukan token saya untuk bulan ini. Tema Hexo yang saya guna sekarang tidak menyokong post pelbagai bahasa, boleh katanya saya tambahkan fungsi ini secara paksa. Kod sumber laman web ini, korang tak perlu pergi Github tengok pun, boleh bayangkan betapa dahsyatnya, hehehe~

Walaupun [membina laman web pelbagai bahasa sangat menyusahkan diri](https://alexhsu.com/en/multilingual), tapi saya fikir, saya orang Malaysia, kalau guna satu bahasa sahaja, semestinya tak boleh meliputi semua golongan yang mungkin baca blog saya. Saya tak harapkan blog saya ada pembaca, tetapi mungkin saya kehilangan peluang untuk orang lain mengenal saya?

Dari segi keliputan, sebenarnya bahasa Cina dan bahasa Inggeris dah cukup. Tetapi... sudah tentulah laman web ini akan dikena rombakan besar, kenapa saya tak tambah banyak sikit bahasa?

**Cina tradisional**: Cina, macam mana pun bahasa ibunda saya, itulah bahasa terbaik untuk mengungkapkan idea saya. Biasanya saya menulis dalam bahasa Cina dulu, baru terjemahkan ke bahasa lain. Memandangkan saya kerap menyertai BlogBlogParty, kebanyakan pembaca blog ini orang Taiwan, yang lebih biasa membaca Cina tradisional.

**Cina ringkas**: Tetapi saya orang Cina Malaysia, kebanyakan kawan offline saya guna Cina ringkas, boleh baca Cina tradisional tak bermaksud mereka suka. Penukaran Cina tradisional ke Cina ringkas sangat senang, guna penterjemah sedia ada sahaja.

**bahasa Inggeris**: Masa universiti nanti, tak kiralah saya sambung belajar dalam Malaysia ke negara lain, bahasa utamanya Inggeris, kemungkinan besar saya akan berendam dalam persekitaran berbahasa Inggeris. Jadi lebih baik sedia payung sebelum hujan.

**bahasa Melayu**: Kalau saya nak bincang hal-hal tempatan (politik?), lebih lancar saya guna bahasa Melayu. Macam saya dah sebut tadi, saya harap saya dapat meliputi semua orang, sekurang-kurangnya dalam Malaysia. Yang penting itu saya suka, saya sudi.

### Harga

Harga untuk berbuat begini sangat besar, setiap kali nak siarkan artikel baru kena tulis dalam bahasa Melayu dan bahasa Inggeris sekali lagi, 2~3 jam dah jadi masa minimum untuk saya menyiapkan satu artikel. Sebelum ini saya pernah pun sebut, menulis artikel [tak senang](/2026/03/28/procrastination) bagi saya, saya pun dah biasa dengan perasaan menulis artikel macam projek besar. Bagi artikel-artikel sebelum ini, saya dah terjemahkan ke Cina Ringkas dahulu; bahasa Inggeris dan Melayu akan saya tambah kemudian bila ada masa

### Kata akhir

Lepas rombakan laman web ini, saya rasa sedikit menyesal pulak, laman web ini sekarang dah gemuk gedempong. Walau bagaimanapun, saya boleh terima lagi, malah ada rasa sedikit suka, kerana ia sepadan dengan perangai saya (seperti meja saya yang sentiasa kacau-bilau), tetapi pembaca boleh terima tak? Itu cerita lain. Saya percaya segala kesusahan ini berbaloi.
